Ce que fait skred fuck skyrock

  • Sur ton téléphone. La vidéo est analysée dans le navigateur. Elle n'est envoyée nulle part.
  • Un carré noir plein. Peint sur l'image avant qu'elle soit réenregistrée : le visage n'est ni flouté ni caché, il n'est plus dans le fichier.

Si tu sais coder

  • Code public. Sous licence libre : github.com/Nctrn17/vesky. Le site sert le même fichier, lisible, sans rien de caché.
  • Aucune trace du visage. test/test-sans-trace.mjs prend deux vidéos identiques sauf les visages, leur pose les mêmes masques : les fichiers produits sont identiques octet pour octet. Aucun filigrane ne peut permettre de retrouver le visage.
  • Aucun envoi. La page interdit au navigateur de se connecter à un autre site que vesky.fr. L'app Android n'a même pas la permission d'utiliser Internet.
  • Bibliothèques d'origine. ONNX Runtime et Mediabunny : test/verifier-tiers.sh vérifie qu'ils sont identiques aux versions officielles. Le modèle de détection est YuNet, réentraîné pour mieux voir la nuit : sa recette est publique.

Ce que skred fuck skyrock ne fait pas

Aucun outil ne trouve tous les visages : un profil, un visage caché en partie ou très petit peut être raté. Touche l'image pour ajouter un masque à la main.

Le carré cache le visage, pas les vêtements, les tatouages, la démarche, le lieu ni la voix.
